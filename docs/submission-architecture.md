# Enquiry submission contract

The current review retains a Next.js server runtime and interactive Quote List. Real form submission is intentionally not activated without configured hosting, durable storage and notification destinations.

The implementation requirements and failure-handling contract are recorded in [the second-pass review](second-pass-review.md#required-submission-implementation-when-configuration-is-supplied). This contract is a launch requirement, not a claim that submission is already implemented.
